In the .csproj, you can edit the build instructions.
You can add new instructions like this:

<ItemGroup>
  <Content Include="config\**">
    <CopyToOutputDirectory>Always</CopyToOutputDirectory>
  </Content>
</ItemGroup>
<ItemGroup>
  <Content Include="assets\**\*.bundle">
    <CopyToOutputDirectory>Always</CopyToOutputDirectory>
  </Content>
</ItemGroup>

To always copy the local "config" and "assets" folders and all of their contents.

You can also add:

<Target Name="CopyCustomContent" AfterTargets="AfterBuild">
  <Copy SourceFiles="$(OutputPath)**\*" DestinationFolder="D:\Path\To\SPT\Install" SkipUnchangedFiles="true" />
</Target>

To copy everything that was built to the "DestinationFolder" of your choice.
(Make it the path to your SPT install to automatically copy it to your game directory.)

You can even add it to automatically zip the folder only when building in release mode, or only copy the mod build to your game directory if it's being built in debug mode.

Just wrap the instructions in this:
<ItemGroup Condition="'$(Configuration)' == 'Debug'">
  // whatever
</ItemGroup>

etc, to only execute the instructions if you build it in Debug mode.

# Debugging 4.0 mods easily

This is for VS, but I presume the setup for Rider is similar.
Anything in `{}` you need to replace with your own path.

1. In your mod project, click `Debug`
2. Select `{ProjectName} Debug Properties`
3. Click `Create a new profile`
4. Set up `Executable` and `Working directory` to the `debug` output of the SPT C# Server (you need to compile it yourself)
5. Rename the profile to whatever you want and close the window
6. Use a post-build or similar to move your mod files (both .dll and .pdb) after building in `debug`. I use:

```bat
xcopy /s /y {mod_folder}\FikaServer\bin\Debug\FikaServer.dll {spt_server}\SPTarkov.Server\bin\Debug\net9.0\user\mods\fika-server\FikaServer.dll
xcopy /s /y {mod_folder}\FikaServer\bin\Debug\FikaServer.pdb {spt_server}\SPTarkov.Server\bin\Debug\net9.0\user\mods\fika-server\FikaServer.pdb
```

7.  Go to `Tools` > `Options` > `Debugging` and disable `Enable Just My Code` if it's enabled
8. Start your newly created debug profile from *your* project
9. Profit
